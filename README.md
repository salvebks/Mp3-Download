# MP3 Downloader

Aplicativo para Windows que permite baixar músicas e playlists em MP3 a partir de links do Spotify e do YouTube, com escolha da pasta de destino e acompanhamento do progresso.

Este repositório é destinado à apresentação do aplicativo e à distribuição dos instaladores. O código-fonte do aplicativo é mantido separadamente.

## Download para Windows

**[Baixar MP3 Downloader 2.5 para Windows (.exe)](https://github.com/salvebks/Mp3-Download/releases/download/v2.5/MP3_Downloader_2_5_Setup.exe)**

Confira os detalhes e o arquivo de verificação de integridade na [versão 2.5](https://github.com/salvebks/Mp3-Download/releases/tag/v2.5).

O botão **Code > Download ZIP** baixa apenas os arquivos de apresentação deste repositório.

## Requisitos

- Windows 10 ou Windows 11 de 64 bits.
- Conexão com a internet para consultar e baixar as músicas.
- Espaço em disco para o aplicativo e os arquivos de áudio.

O instalador inclui os componentes necessários. Não é preciso instalar Python.

## Instalação

1. Baixe o instalador pela seção Releases.
2. Se já estiver usando o aplicativo, feche-o antes de atualizar.
3. Execute o instalador e siga as instruções da tela.
4. Abra o MP3 Downloader pelo atalho criado.

## Como usar

1. Cole o link da música ou da playlist.
2. Escolha a pasta de destino e a qualidade desejada.
3. Clique em **Baixar MP3**.
4. Acompanhe a música atual, a etapa e o progresso.
5. Ao terminar, clique em **Abrir pasta** para acessar os arquivos confirmados.

O aplicativo abre diretamente, sem solicitar uma senha.

## Recursos

- Download de músicas e playlists.
- Conversão para MP3 e seleção da qualidade.
- Indicação de progresso e resultado da operação.
- Nomes legíveis para as faixas do Spotify, com espaços e acentos.
- Tratamento de nomes iguais sem sobrescrever faixas diferentes.
- Seleção automática de fonte para as músicas identificadas pelo Spotify.
- Atualização dos componentes pelo menu Configurações.

Os links do Spotify são utilizados para identificar as músicas. O áudio é procurado em fontes externas, e sua disponibilidade depende dos serviços de origem.
